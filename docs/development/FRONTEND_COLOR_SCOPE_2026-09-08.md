# 换肤覆盖范围优化

日期：2026-09-08。本轮承接 RGB 选色实现，按用户反馈移除四种预设并加强换肤效果。

## 原因与处理

- 原菜单仍占用较大空间展示四种预设：删除预设名称、列表、样本、箭头键选择逻辑和相关样式，只保留色谱、RGB/HEX 输入、预览、应用及“重置颜色”。
- 原主题仅覆盖少量强调色：为自定义颜色加入侧栏底色、顶栏底色和分隔线、表头底色、当前导航项及新建实验按钮；选中区域色阶从 8% 增至 16%。
- 主内容区仍保留中性背景，图表系列色、成功/警告/错误状态不参与换肤，避免改变数据含义。

顶部入口统一为“换肤”并显示当前颜色样本。打开后聚焦 HEX，Escape 和关闭按钮返回入口；未确认编辑不会应用。重置清除所有新增覆盖，不改变深浅模式。

旧版颜色标识仅在内部继续兼容已有浏览器设置；不再暴露四种预设入口，也不强制迁移用户偏好。RGB 原值保持不变，应用色根据新增背景重新计算对比度。

## 涉及文件

ThemeSwitcher.vue、ThemeColorEditor.vue、theme/index.ts、theme/color.ts、foundation.css、dark.css、主题翻译目录以及对应单元和浏览器测试。未修改后端、Bridge、接口、报告模型、路由或业务控制器。

## 设计边界

不是把所有区域染成同色，而是让全局导航和交互状态明确响应个人配色。继续沿用上一轮记录的 RGB 转换、Pointer Capture 和文字对比度规则；不新增第三方素材。选极亮或极暗颜色时实际强调色仍会适配对比度，原始颜色在编辑器中保留。
