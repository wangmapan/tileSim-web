## 2. 修改前分级审查

人工复核执行页的实际快照又确认一项既有 P1：不带显式颜色的请求 Token 构成图收到空色板，数值和坐标轴存在但柱条不可见。现已为未指定颜色的序列提供浅／深色 token，并保留已有显式颜色；新增单元复现和浏览器可见柱条断言。此项不改变任何数据值，也不依靠更新空图快照掩盖问题。

| 优先级 | 问题与定位                                                                      | 影响                                                             | 本批处理                                                               |
| ------ | ------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------- |
| P0     | 暂未确认新的接口或证据数值错误                                                  | 实际部署不可达，不能把夹具通过等同于真实部署正确                 | 保持证据边界；真实部署复验受阻                                         |
| P1     | 总览 `.hero-measure` 固定最小列宽、大字号和外层裁切组合，在 1100px 桌面截断时长 | 关键数字不能完整阅读                                             | 调整列宽、字号、换行和内边距；新增元素级溢出断言                       |
| P1     | `AppHeader` 用 label 包住隐藏文件输入，没有可聚焦导入按钮                       | 键盘用户难以启动导入                                             | 原生 button 触发同一个 input，保留 accept/multiple/onImport/reset 行为 |
| P1     | `ExecutionChart` 的 mounted await 之后无卸载保护，仍可创建 MutationObserver     | 路由快速离开或测试 teardown 时泄漏观察器，存在 document 访问风险 | 已先用测试复现；增加取消保护、帧取消和观察器释放                       |
| P1     | 深色示例提示使用半透明白底                                                      | 回归发现说明文本和操作文字对比度不足                             | 改为语义表面 token，并由双语双主题 axe 验证                            |
| P2     | 全局引导框、重点警告、证据条、示例提示和渐变摘要竞争首屏                        | 用户先读到重复说明，而不是指标和可执行动作                       | 引导变为原生 disclosure；真实证据条和错误继续直接显示                  |
| P2     | 总览扫光、大渐变、四个同质统计卡及数字入场动画                                  | 偏模板化，装饰多于信息                                           | 去扫光和摘要渐变；四项现有指标变为分隔带，不新增趋势或数字             |
| P2     | 容器圆角、阴影、控件和 Tooltip 排版不一致                                       | 页面间缺少稳定层次                                               | 公共 panel/control/overlay token；移除公共 panel 阴影和 header blur    |
| P2     | 空状态居中大留白，视觉像加载占位                                                | 任务名称和下一步不突出                                           | 紧凑左对齐，保留现有说明和有效操作入口                                 |

| P2     | 部分中文界面仍以旧模块编号、hosted 和受控场景代码作为主要文案                   | 不完全符合当前产品术语                                           | 后续建立显示级中文映射；不修改报告字段、Pointer 或 canonical ID        |
| P2     | 同一次离线启动同时展示服务未连接和契约错误                                      | 两项提示可能被理解为两个独立故障                                 | 保留失败关闭行为；后续在前端状态模型中梳理因果提示，不改后端           |
| P3     | 后续网络拓扑、拥塞与反压还可加强时间窗关联                                      | 需要真实字段和语义充分支撑                                       | 本批不绘制猜测的路径、等待关系或无数据迷你图                           |
