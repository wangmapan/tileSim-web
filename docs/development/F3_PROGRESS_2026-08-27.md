## 已完成

- `GET /api/manifest` 返回 `tilesim.bridge.api.v1`、error/artifact manifest schema、known report identities 和 deterministic `schema_set_revision`。
- 所有 API JSON 和 artifact 响应携带 `X-Request-ID`、API version 和 schema-set revision；合法客户端 request ID 可贯穿响应。
- API 错误统一为 `tilesim.bridge.error.v1`：包含 `code`、`message`、`field_path`、`retryable` 和 `request_id`。前端同时兼容旧字符串错误。
- `GET /api/runs/{id}/artifacts` 仅枚举 allow-list JSON，返回字节数、SHA-256、schema identity、report kind 和媒体类型。
- 前端启动时校验 API manifest；未知 API/error/artifact contract 失败关闭。
- 未提供 manifest 的旧 Bridge 进入只读兼容模式：历史报告继续可读，新运行关闭；显式返回的不兼容版本不会降级为 legacy。
- 前端打开或恢复运行时读取并校验 artifact manifest；报告正文仍使用现有 reports endpoint。
- GET 仅在 transport failure 时切换 fallback root；HTTP error 不重试，POST 不自动重放。
- 未知 API endpoint、run、artifact 和 template 返回结构化错误；rename body 也执行 2.1 MB 上限。
- 当前未重启的 5173 legacy Bridge 实测进入只读模式，`week6-local-snapshot-smoke` 历史运行可见，源码/CLI 均为 `e06cab9`，横向溢出和页面错误均为 0。
- `POST /api/runs` 强制合法 `Idempotency-Key`；canonical JSON payload 使用 SHA-256 绑定。同 key/同 payload 返回同一 run 且不重复启动，同 key/异 payload 返回 409。
- 幂等 key 与 payload digest 进入私有 metadata；清空进程内 run map 后仍可从磁盘恢复，公开 run 响应不泄漏这两个字段。
- create-run 校验错误返回精确 JSON Pointer；已覆盖 `/scenario_id`、`/headers/Idempotency-Key` 和 `/overrides/fabric/scale_out_latency_us`。
- `GET /api/runs/{id}/events` 提供 SSE：event ID `1` 为 active、`2` 为 terminal，支持 `Last-Event-ID`；服务端 heartbeat/timeout 后关闭本次流。
- 前端同一序列化 payload 在 POST transport failure 后保留并复用 key；收到明确服务端响应后不再保留 pending key，已创建 run 可继续恢复等待。
- `bridgeApi.waitForRun()` 优先消费 SSE；断流时带 `Last-Event-ID` 重连一次，服务端 timeout 或再次断流后回退 `GET /runs/{id}` 轮询。
- Batch B 门禁：TypeScript、contract drift、ESLint、Prettier、44/44 Vitest、17/17 Bridge unittest、5/5 desktop Playwright、production build 和 `git diff --check` 通过。构建为 226.12 kB JS / gzip 71.99 kB。

## Batch B review closure

- 幂等 reservation 现在先原子写入 metadata，再登记内存和启动执行；落盘失败返回 retryable 500，且不会启动 CLI。
- metadata 更新使用同目录临时文件、file fsync 和 atomic replace；WSL/NTFS 不支持 directory fsync 时安全降级。
- metadata 已移出公开 artifact allow-list；`/files/metadata` 返回 404，幂等 key、payload digest 和 Bridge 实例字段不会通过 run/SSE/artifact API 暴露。
- metadata 记录 Bridge 实例；新实例读取到无主报告的旧 `preparing/running` 时转为 `bridge_execution_interrupted`，SSE 可返回终态。
- pending payload/key/run ID 进入 session-backed 全局状态；页面切换和刷新后仍可复用，只有确定的非 retryable 4xx 才清除未确认 key。
- artifact manifest revision 必须等于启动 manifest revision；版本化报告和输入逐项验证 SHA-256 与 schema identity 后才进入 adapter/UI，JSON 面板按需加载也执行相同校验。
- Review closure 门禁：51/51 Vitest、19/19 Bridge unittest、5/5 desktop Playwright；production build 229.49 kB / gzip 72.93 kB。
