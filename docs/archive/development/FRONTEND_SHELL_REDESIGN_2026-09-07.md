## 设计依据

本轮采用 reference-led redesign 和公共设计系统对齐。沿用并重新审阅第四批的十项官方参考，完整来源、采用原因、不照搬部分及许可规则见 `FRONTEND_ATTRIBUTION_RESEARCH_2026-09-07.md`。

本轮再次直接读取官方实质内容：

- Linear：<https://linear.app/now/how-we-redesigned-the-linear-ui>。借鉴降低应用骨架噪声、增加导航密度与视觉对齐，不复制品牌或问题管理流程。该文章发表于 2024-03-28，不声称是当前产品截图。
- GitHub Primer DataTable：<https://primer.style/product/components/data-table/>。借鉴稳定列、实体行、按需详情与键盘操作，不复制 GitHub 页面或资产。
- Grafana dashboard best practices：<https://grafana.com/docs/grafana/latest/dashboards/build-dashboards/best-practices/>。借鉴先摘要后下钻、同量纲比较和减少认知负担，不照搬监控大屏或实时状态。

通用 Web 工具没有返回可读内容，改用直接 HTTPS 获取；正文记录位于 Git 忽略的 `runtime/visual-review/batch7/research.json`。未使用第三方图片、商标、截图或字体作为产品资产；保留现有 Lucide 依赖。参考只用于设计原则分析，没有据此取得素材再分发许可。

## 实施范围

- `App.vue`、`AppHeader.vue`、`AppSidebar.vue`：单行上下文、较窄中性侧栏、明确当前导航、帮助工具栏插槽；原路由和导入报告操作保留。
- `PagePrimer.vue`：默认折叠的页面帮助；跨页关闭、Escape 关闭并归还焦点；原完整引导仍可访问。
- `EvidenceStrip.vue`：紧凑运行上下文，避免通过文案提升证据等级；完整来源、校准、范围及原始身份仍可展开。
- `OverviewView.vue`：运行摘要、数值、瓶颈归因、通信域表；删除“下一步”等劝导段落；不改变任何数值、排序、单位或缺失语义。
- `ExecutionView.vue`：简化标题与指标分区，保留资源并列、所有图表、报告导出与字段证据。
- `FabricView.vue`、`ValidationView.vue`：移除重复介绍，保留未报告、校准、缺口与请求／实际精度差异。
- `StatCard.vue`：可选 hint 不再产生空元素。
- 公共样式：`foundation.css`、`dark.css`、`evidence.css`、`overview.css`、`workbench.css`、`execution.css`、`experiment.css`；四个配色选择保留，公共中性色一致。
- `chart-options.ts`：reduced-motion 不仅将 duration 设为零，也明确关闭 ECharts animation；未改变实例、事件绑定、调度或卸载策略。
- 英文新增文案独立放入 `shell-review.ts`；相关组件、单元和浏览器断言同步更新，没有删除业务断言。
