## 3. 设计依据与取舍

沿用 `FRONTEND_VISUAL_AUDIT_2026-09-06.md` 中已记录的 14 个官方参考及来源、许可与不照搬范围。本批没有新增已完成的在线素材调研，不将此前参考描述为今日重新核验的产品事实。

- GitHub Primer、Linear：采用对齐、分隔与中性层级，减少容器，不复制品牌界面。
- NVIDIA Nsight Systems、Ray Dashboard：区分整体观察与局部详情，保持实际时间、资源和单位语义；不增加虚构 Timeline 或 Cycle 能力暗示。
- Datadog、Jaeger：摘要到精确证据的稳定深链；保留 artifact、SHA 与原始 JSON Pointer，而不是根据显示标签重建关联。
- Grafana：关系表达依赖真实字段；本批没有生成拓扑图，正式拓扑关联不可用时继续说明边界。

没有导入第三方图片、品牌图形、字体或产品代码，未取得也未假定这些资产的再分发许可。使用既有 Lucide、Vue、CSS 和 ECharts；不增加网格、粒子、光效、迷你趋势或营销数字。
