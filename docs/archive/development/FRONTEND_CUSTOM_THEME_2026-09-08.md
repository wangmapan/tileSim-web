# 自定义 RGB 主题色

日期：2026-09-08。范围仅限前端换肤功能，不修改后端、Bridge、路由、报告数据或证据含义。

## 审查与设计

原菜单仅提供四个固定预设，无法选择任意颜色。保留预设和独立的浅色/深色模式，增加一个可视色谱、色相条、RGB 数值和 HEX 输入区。菜单不再为每个预设显示营销式说明，以紧凑色样和名称替代。

色谱使用 HSV 坐标表达饱和度和明度，RGB/HEX 输入与之联动。渐变仅用来表达色彩空间，不是页面装饰。预览区显示原始选色、实际链接色和按钮样式。只有点击“应用自定义颜色”才更新界面；Escape、点击外部或重新选择预设均不会应用未确认的编辑。

原始 RGB 保存在本地浏览器。根据深浅模式，界面强调色会向更暗或更亮的方向调整，以保证指定中性背景上的文字对比度。RGB 原值不会被该调整覆盖。告警、错误、成功及图表系列色保持不变，不让个人配色改变数据语义。

## 实现

- src/components/ThemeSwitcher.vue：预设与自定义编辑的非模态面板，保留预设箭头键选择及 Escape 返回焦点。
- src/components/ThemeColorEditor.vue：独立编辑草稿、色谱拖选、色相、RGB/HEX 校验和应用前预览。
- src/theme/color.ts：颜色格式校验、RGB/HSV 转换、对比度与强调色计算。
- src/theme/index.ts：custom 主题类型、独立颜色存储、刷新恢复、切换外观和清除预设覆盖。
- src/styles/foundation.css：紧凑预设、面板尺寸约束、自定义按钮文字颜色；深色预设样本保持其颜色。
- src/i18n/workstreams/theme-color.ts：独立英文文案目录，通过现有 workstream 汇总接入。

没有新增依赖、字体、图像、图表或定时器。色谱拖动仅更新编辑器草稿，不触发全局主题和图表重绘。拖选使用元素级 Pointer Capture，在抬起或取消时释放。二维色谱不进入无障碍树，键盘和辅助技术可通过有标签的 RGB、HEX 与色相控件完成同等选色。

## 限制与后续

自定义的是界面强调色，而不是把全部背景和数据色板染成同一颜色。选择非常浅或非常暗的颜色时，实际文字/按钮颜色可能与原始色样不同；预览与说明明确呈现这一点。颜色配置仅存本浏览器，不上传后端或同步其他设备。既有主入口构建体积提醒未在本轮关闭。
