## 审查与决策

- P1：较窄窗口中，资源证据链自身最小宽度大于父级，父级裁切右侧内容。取消容器最小宽度，由现有网格内部滚动；增加可聚焦的命名区域，保留并列资源关系。
- P2：P99 三个同质卡片重复顶边、浅色底和药丸标签；`single_request` 使用警告配色，但该语义本身不是风险。改为原生指标表，仅保留行分隔线、列对齐和当前请求文字。
- P2：选择规则和成功校验说明重复出现，压低数值、请求身份和证据入口的权重。将每项原始规则、选择语义、字段名和校验详情收进原生 disclosure；无效关联始终在收起状态显示警示文字，不只靠颜色。
- P2：侧栏 CSS 图形与浏览器旧图标不一致，且标识有入场动画。替换为原创几何 TS 单色字标，使用同一 SVG 源；移除旧方框、旧动画和相关 keyframes。
- P2：证据链标题区的英文眉题和旧编号说明重复。保留“请求证据链”与请求选择，不把旧实现编号作为该区标题的主要词汇。
- 邻近区域一并去除装饰容器：分段按钮改下划线页签，运行身份和跨页入口改为行内文字，资源节点与输出记录只用分隔线组织，绑定状态不再使用绿色药丸。并列资源的分组与原有顺序不变。
