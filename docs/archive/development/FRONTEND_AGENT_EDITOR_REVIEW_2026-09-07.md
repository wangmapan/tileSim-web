- P1：提交与证据边界被长表单推到首屏外。改为问题编辑区与证据边界双栏，1100／1440／1920px 下提交操作在首屏；较窄窗口回到单栏。

- 本批优先解决 Agent 编辑区，未改执行页大型图表布局，避免一次扩大到全部页面。

## 图标语义与设计规则

| 任务         | 图标              | 作用                             |
| ------------ | ----------------- | -------------------------------- |
| P99 请求     | Gauge             | 分位性能分析                     |
| 尾延迟       | Activity          | 延迟变化与异常分析               |
| 可信度       | ShieldCheck       | 校准与验证范围                   |
| 条件优化建议 | SlidersHorizontal | 参数与策略调整；不表示建议已验证 |

所有任务图标 16px、1.5px 线宽、currentColor；均为 `aria-hidden`，radio 的完整文字仍提供可访问名称。图标不单独承载状态，不替代文字，不引入持续动画。
