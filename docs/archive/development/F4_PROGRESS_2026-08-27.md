# F4 结构与状态重构

**状态**：2026-08-27 validated  
**范围**：电脑网页端、local Bridge；不改变报告字段、证据规则或 API contract

## 目标

- URL 可恢复页面和 run 上下文。
- UI state、server state、报告 workspace 分离。
- 页面、feature、API、Bridge 执行和持久化之间有稳定边界。
- 大文件按职责拆分，后续修改不需要同时触碰无关模块。

## 已完成

### 应用与状态

- Vue Router 懒加载；地址固定为 `/<view>?run=<run_id>`，支持刷新、前进和后退。
- run 快速切换使用 synchronization revision 丢弃过期响应。
- Pinia 分别拥有 workspace、session、bridge 和 history；`useDashboard()` 保留为兼容 controller facade。
- TanStack Query 管理 Bridge、history、run evidence 和 artifact server state。
- Query key 包含 run ID、backend/source revision、schema-set revision、artifact ID 和 SHA-256。
- dashboard 的 state assembly 与 localStorage selection persistence 已从 controller 拆出。

### Feature 与依赖

- view 通过 feature 公共 `index.ts` 使用 Bridge 能力，不直接请求 `lib/api`。
- Experiment view 拆为 identity、capability、input、design-space 和 submit 组件。
- execution inspector 拆为 types、aggregations、records、stats 和 builder；页面与测试都使用 feature 公共入口。
- `pnpm deps:check` 阻止循环、基础层反向依赖、跨 feature 内部导入、view 直连 API，以及 UI primitive 访问 store/API/feature。
- `main.css` 按 foundation、evidence、overview、analysis、history、experiment、design-space、execution 拆分，并保持原级联顺序。

### Bridge

```text
api/responses.py             response envelope、headers、CORS、SSE
contracts/validation.py      纯字段与范围校验
contracts/run_request.py     run request -> validated command
infra/identity.py            Git、部署与 runtime identity
repositories/runs.py         metadata、artifact manifest、恢复与原子写入
services/execution.py        输入物化、CLI 执行与终态收敛
server.py                    配置、兼容 wrapper、路由和端点协调
```

- `server.py` 从约 65 KB 降到约 31 KB。
- `server` wrapper 保留既有脚本和故障注入测试接口。
- handler 不再实现 Git identity、字段校验算法、artifact persistence 或 CLI 执行细节。
