# Evidence Agent 结果阅读区审查

日期：2026-09-07，第十轮。继续上一轮减少容器、降低重复提示权重的方向，范围限于 Evidence Agent 结果区及相关编辑区提示。仅修改前端，不调用真实 Provider，不改变生成问题、任务枚举、幂等契约、草稿内容或证据绑定。

## 优先级与方案

- P1：原来的“可以开始提问”仅表示证据快照就绪，可能与“AI 解释当前不可用”同时出现。改成“证据就绪”，保留独立能力判断与提交禁用条件。
- P2：每条陈述单独套圆角卡片，分类数量用药丸显示，结果外框和引用按钮再次包裹。改为左侧分类／数量、右侧有序内容的分组列表；用分隔线组织，不增加统计信息。
- P2：英文眉题与“每条事实单独验证引用”等重复说明抢占首屏。改为“分析草稿”和一条必须人工复核、不修改原始报告的说明，不把引用结构校验表述为结论真实性已验证。
- P2：“专业详情”重复用于不同对象，引用入口只写“打开原始证据”。改为“运行与模型标识”“陈述元数据”“引用元数据”；引用直接显示工件与 JSON Pointer，保留明确的无障碍名称。
- P2：服务和隐私详情在结果之前。结果移至提交区之后、配置详情之前，保留原有生成后焦点和滚动行为；服务和隐私入口改为分隔线式展开项。
- P2：未选择请求时暴露内部占位 `request_not_selected`；中文预览混入 artifact、fidelity。替换为自然中文，原始字段和枚举保留在详情，不修改来源等级或保真度含义。

## 文件与边界

- `EvidenceAgentResultPanel.vue`：仅显示层调整，保留三类主要结果和可选补充说明。空类别仍明确显示未返回内容，不把缺少限制解读为没有限制。
- `EvidenceAgentPanel.vue`：结果与辅助详情调序，修正就绪提示语义；提交与恢复逻辑不变。
- `EvidenceAgentSubmissionPreview.vue`：缺少请求的展示、工件及保真度术语。零引用、真实轨迹／合成轨迹／兼容性辅助轨迹，以及 requested/resolved fidelity 仍分开。
- `evidence-agent.css`：只处理相应结果与展开项，不对全站做全局去边框。部分、拒答、失败、超时保留可见的状态和原因，颜色仅辅助风险表达。
- 组件及 E2E 测试验证陈述原文、分组和原始索引不变；SHA、Pointer、run 身份及引用元数据保留。

## 素材与性能

沿用前几轮的工程软件排版原则与已核验图标体系。本轮没有新下载的图片、字体、图标或运行时依赖，反而移除重复装饰图标。未新增动画、监听器、图表、定时器或数据计算；生产体积以 runtime 本轮构建对照为准。
