## 4. 功能、语义与性能约束

浏览主题不更改 URL 或当前运行。明确进入相关分析页面时保留 run、evidence_request，丢弃不属于新页面的旧 evidence_pointer。新建实验、历史和全局校准页沿用其原有上下文边界。

正文保留真实、合成与兼容 Trace 来源的区别，requested/resolved fidelity、GPU 不等于 Cycle、Tile 是建模粒度、资源语义并列、控制平面不是第六目标层、缺失不等于零、uint64 无损、AI 结论需要人工确认等约束。

文档窗口使用原生模态语义，支持 Escape、首尾键盘循环、关闭后回到入口。定位页面时展开已有折叠区域并保留焦点，离焦或卸载后清除临时 tabindex 和监听器。关闭窗口恢复原滚动状态；快速取消不会遗留弹窗。没有持续动画、模糊滤镜、装饰背景、图表、轮询或新的网络请求。

生产文档面板独立 chunk 约 6.28 kB（gzip 2.63 kB）。总览打开帮助不加载 ECharts，由浏览器测试约束。主入口仍包含帮助内容和共享翻译，不能将面板按需加载描述成全部文档均延迟加载。
